DESU - DESKTOP ENVIRONMENT SERVICE
File: kernel/service/desu.asm
Author: arfy slowy

OVERVIEW
Desktop environment service providing a composited graphical interface
with window management, mouse cursor, and object-based rendering.

LOOP

service_desu:
  init.asm -> allocate lists, create framebuffer/workbench/cursor objects
.loop:
  call service_desu_object         - flush dirty objects to zone
  call service_desu_cursor         - track mouse, LMB click/drag, raise z
  call service_desu_fill           - composite all fill operations
  jmp .loop

SUBFILES

| File | Description |
|------|-------------|
| config.asm | Constants: object flags, structure definitions, limits (OBJECT_EXTRA: size+flags only) |
| data.asm | Global state: semaphores, object/fill/zone lists, cursor bitmap, tmp test object |
| init.asm | Invert cursor alpha, allocate lists, fill workbench bg, insert workbench + tmp test object |
| cursor.asm | Mouse tracking, LMB click (find + raise z), drag (move), zone update, inline fill |
| object.asm | Object insert (simplified), flush (service_desu_object), find, remove, up (raise z), move (drag) |
| fill.asm | Fill insert by register/object, overflow check, composite to framebuffer with clipping |
| zone.asm | Dirty-region tracking, occlusion culling, screen bounds clipping, direct fill insert, zone list reset |
| keyboard.asm | Keyboard input handling (Alt key state) |
| sleep.asm | Idle loop when no objects present |
| panic.asm | Out-of-memory panic handler |
| gfx/cursor.data | Binary cursor pixel data (12x19 ARGB) |

OBJECT STRUCTURE

SERVICE_DESU_STRUCTURE_OBJECT:
  field  - x, y, width, height (4 x 8 bytes)
  address- pixel data pointer (8 bytes)

SERVICE_DESU_STRUCTURE_OBJECT_EXTRA:
  size   - byte count of pixel data (8 bytes)
  flags  - object flags (8 bytes)

Note: id, pid, length, name fields removed from EXTRA.

OBJECT FLAGS

  visible   bit 0 - object is rendered
  flush     bit 1 - object needs redraw
  fixed_xy  bit 2 - position locked
  fixed_z   bit 3 - z-order locked (cannot be raised)
  fragile   bit 4 - hidden on LMB click (popup behavior)
  pointer   bit 5 - mouse cursor object (singleton)
  arbiter   bit 6 - privileged object (bypasses z-ordering)

RENDERING PIPELINE

  1. Object flush (service_desu_object) marks dirty objects
     into the zone system
  2. Cursor runs — tracks mouse deltas, handles LMB click
     (find object, raise z-order via up), handles drag
     (move old/new zone regions), queue cursor fill
  3. Zone system splits damaged regions around opaque objects
     with screen bounds clipping, inserts fills, clears zone
     object after processing, resets list at end
  4. Fill list is composited to framebuffer with per-pixel
     alpha blending (pixels with alpha=0xFF are opaque,
     alpha=0x00 are transparent)

NOTES

  - Mouse interaction restored: LMB click finds object at cursor
    (service_desu_object_find), raises it to top z-order
    (service_desu_object_up via insert+remove), and dragging
    moves the selected object (service_desu_object_move)
    with old/new zone regions registered for redraw.
  - service_desu_object_move splits movement into X and Y
    offset components, handles left/right/up direction,
    and calls zone + fill at end to flush changes.
  - Cursor uses r14/r15 for delta tracking instead of r10/r11.
  - Loop order: object → cursor → fill (fill always last).
  - Zone loop uses .entry/.loop pattern; zone object cleared
    before advancing; screen bounds clipping applied
    (left ≥ 0, top ≥ 0, right ≤ width, bottom ≤ height).
  - Overflow panics on fill/zone inserts (xchg bx, bx + jmp $).
  - Init fills workbench with dark background (0x00101010)
    and creates a tmp test object (red 32x32 square).
