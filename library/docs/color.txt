COLOR - ALPHA BLENDING & INVERSION
File: library/color.asm
Author: arfy slowy

OVERVIEW
Provides ARGB pixel alpha blending and alpha inversion routines.

FUNCTIONS

library_color_alpha:
  Alpha-blends two ARGB pixels.
  Input:  RSI = pointer to source pixel (foreground, 4 bytes)
          RDI = pointer to destination pixel (background, 4 bytes)
  Output: RAX = blended ARGB pixel value
  Uses 8-bit alpha channel from source byte [rsi+3].
  Performs per-channel blending: result = src * a + dst * (1-a)

library_color_alpha_invert:
  Inverts the alpha channel for an array of pixels.
  Input:  RSI = pointer to pixel array
          RCX = number of pixels
  For each pixel: if alpha > 0, decrement then bitwise NOT;
                  if alpha == 0, set to 0xFF (NOT 0x00 = 0xFF).
